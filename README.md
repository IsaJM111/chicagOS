# chicagOS
An OS that is Chicago themed, has many fully functional apps, and a central file system. built entirely with HTML, CSS, and JavaScript. No external libraries or packages were used.

# Features => Apps
- Notes app
  - Add, delete, save, and load notes
  - Multiple notes open at once
  - Notes save after app is closed
- Calculator app
  - Standard 4 function calculator
  - Delete button, remove typos without clearing the whole field.
- Gallery app
  - View preset images, and upload custom images
  - Previous/next navigation
  - Grid view
- Mind Map app
  - Interactive node editor
  - Node selection
  - Zoomable, infinite workspace
- Browser app
  - Browser home page
  - Quick shortcuts
  - Address bar
  - Browsing history
  - Embedded webpages
- Paint app
  - Drawing canvas
  - Adjustable brush size, color picker
  - Save and load paintings
- Music app
  - Add audio files from computer
  - Play/pause, forward, back
  - Forward/backwards time navigation, volume control
  - Playlist sidebar
- Terminal app
  - Command input
  - 8 preset commands, including opening and closing applications and displaying current time and date
- Settings app
  - Wallpaper selection
    - Classic wallpaper
    - Animated wallpaper
  - Quote toggle
- Files app
  - Virtual file system using `IndexedDB`
  - Built-in folders
    - Desktop
    - Notes
    - Paintings
    - Pictures
    - Music
    - Downloads
  - Create, rename, and delete custom folders
  - Files saved from Notes, Paint, Gallery, and Music all appear in designated folders

# Features => Desktop
- Animated startup sequence

- File app and File system
- All windows draggable and closable

- Interactive desktop
